ENTRE TAZAS

Sitio web académico desarrollado con HTML5 y CSS3.

Páginas:
- index.html
- metodos.html
- recomendaciones.html

Tema integrado:
- CSS Grid
- Diseño adaptable
- Open Graph en la página principal

Para publicar en GitHub Pages:
1. Sube todo el contenido de esta carpeta a un repositorio.
2. En Settings > Pages selecciona Deploy from a branch.
3. Selecciona la rama principal y la carpeta raíz.
4. Guarda y espera a que GitHub genere la URL pública.
